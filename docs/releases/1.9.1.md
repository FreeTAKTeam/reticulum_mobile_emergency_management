# REM 1.9.1: Event icons on the map

This release redraws events on the map as category icons with a popup that opens the event, and fixes three MECP decoding details.

- **Event icons (#377):** each event on the map is now a square badge with its MECP category icon, coloured by severity (Mayday red, Urgent yellow, Safety green, Routine grey). Mayday also carries a "!" mark. Events that are not MECP get a grey note icon. Coloured dots are again used only for presence.
- **Event popup (#377):** tap an event to see its icon, decoded label, severity, details, callsign and code, coordinates and update time. "Open event" jumps to that event in the Events screen, which clears its filters, scrolls to the event and outlines it.
- **First position and language win (#373):** when a message has several coordinates or language hints, the first one is kept, as MECP rule 5 requires.
- **MECP 1.4.1 codes (#375, #376):** M16 is shown as "Medical supply drop needed" instead of a bare code, and R03 reads "ETA [time]".

Only the app screens changed. The native runtime, the plugins and the Fabric (formerly LXMF-rs) pin are the same as in 1.9.0: release `v0.17.0` ([`99fc770e83ed`](https://github.com/FreeTAKTeam/LXMF-rs/commit/99fc770e83ed56eec81a23d8b4b864fe2cfde80e)).

## Known limits

- An open event popup closes if a new event arrives at that moment.

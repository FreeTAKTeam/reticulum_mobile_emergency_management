# REM 1.2.9 Release Notes

REM `1.2.9` updates the native Reticulum/LXMF foundation to the stable
LXMF-rs `v0.9.9` crate set and includes the RNode configuration improvements
merged since REM `1.2.8`.

## LXMF-rs 0.9.9 baseline

- The native runtime now builds against the `0.9.9` releases of
  `reticulum-rs`, `reticulum-rs-transport`, `lxmf-wire`, `lxmf-sdk`, and
  `lxmf-runtime`.
- CI and Android plugin builds check out the immutable LXMF-rs `v0.9.9`
  release commit
  `51fd3beebdace78d6c7f38748c6bcfe452032559`.
- The upstream baseline includes Reticulum 1.4.2 routing, resource-transfer,
  lifecycle, interface-policy, and interoperability improvements. REM keeps
  its existing compiled Rust bridge architecture; no LXMF protocol behavior
  is reimplemented in TypeScript.

## RNode configuration

- RNode LoRa settings now preserve an explicit frequency in hertz across the
  mobile, TypeScript bridge, UniFFI/JNI, and Rust runtime layers.
- Region presets cover US915, EU868, AU915, AS923, IN865, KR920, and RU864.
- Changing a region updates the default frequency while preserving deliberate
  custom frequency overrides.
- Unknown regions and profiles are rejected at the native runtime boundary.

## Platform

- Android version name: `1.2.9`
- Android version code: `262251622`
- LXMF-rs baseline: stable `v0.9.9`, pinned at
  `51fd3beebdace78d6c7f38748c6bcfe452032559` for reproducible builds.
- Android is the release target. iOS compilation and CocoaPods are not release
  gates for this build.

# REM 1.4 testing tag

REM 1.4 is the two-phone field-test baseline for the Android RNode receive and
transmit repairs. It uses the LXMF-rs `0.10.1`-compatible repair revision
`b3b67c1bf4d3fc6697c83860d2e3304c696f25cd`.

## Test focus

- Keep one owner for each bounded native RNode read so cancelled Rust futures
  cannot consume and discard later BLE notifications.
- Buffer KISS frames across BLE notifications without requiring a complete
  frame or a 173-byte ATT MTU.
- Respect RNode firmware queue readiness before admitting another payload.
- Bind two-phone HIL evidence to the exact signed APK, signer, REM revision,
  and LXMF-rs revision installed on both devices.
- Report background event and telemetry fan-out failures per destination with
  their real native error code instead of mislabelling them as `NotRunning`.

The `1.4` tag identifies a physical-testing build. It does not by itself claim
that a public GitHub release or a new exact-head LoRa acceptance run has been
completed.
